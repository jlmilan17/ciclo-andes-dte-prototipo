# Esquemas de demostración (ZG-11)

Estos esquemas describen una **estructura de demostración** inspirada en los DTE salvadoreños.
**No se afirma conformidad** con los esquemas JSON oficiales del Ministerio de Hacienda.
Están aislados en esta carpeta para poder ajustarlos contra la documentación técnica oficial.

El simulador del MH (`mh-sim/`) valida contra estos mismos esquemas, como haría el MH real con su esquema publicado.
